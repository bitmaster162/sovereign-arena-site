Продукты

ContinuityOS (open source, Apache-2.0)

Локальная память для агентов: один SQLite-файл, гибридный recall (слова+смысл), bi-temporal факты («что было правдой в марте?»), авто-извлечение фактов из сессий, governance-gate на инструменты, fork/merge состояния. MCP-сервер для Claude из коробки. Бенчи в репо — честные, без маркетинга.

Sovereign Arena (лаборатория-шоу)

150+ конфигураций в paper snapshot 2026-07-22; current market feed не подтверждён. Еженедельный вердикт KEEP/WATCH/KILL по OOS-консистентности. Memento case-bank: система помнит, какие сетапы в каком режиме зарабатывали, и пускает ботов только в «зелёные ячейки» памяти.

Battles (шоу-слой)

FAQ

Это реальные деньги?
Нет — арена торгует paper с реалистичными издержками. Это лаборатория и пруф методологии, не сигнал-сервис.
Почему верить цифрам?
Всё форвард (не бэктест), с комиссиями и слиппеджем; вердикты по фиксированным правилам (мин. 40 закрытых сделок + OOS-консистентность); решения ИИ — в hash-chain.
Что такое «режимы»?
Рынок классифицируется (тренд/флэт/перегрев) — стратегии торгуют только в «своих» режимах. Edge = permission system, not signal system.
Чем ContinuityOS отличается от Mem0/Zep?
Локальность (один файл, без облака), bi-temporal факты и governance-gate в одном пакете. Recall-бенчи — не наш козырь, и мы честно пишем это в репо.
Как начать с ContinuityOS?
Открой GitHub source/README; registry install и CLI smoke этим кандидатом не квалифицированы. Для Claude: cos serve (MCP).
Откуда берутся гайды?
Из практики арены: сначала эдж живёт и измеряется — потом становится гайдом.
